The `SingleSelect` component is not available in OUI.

<br />
For single selection functionality, consider using:

- the [`ComboBox`](/docs/components/combo-box) component for a component that allows selection and filtering via text input, or
- the [`Select`](/docs/components/select) component for a traditional dropdown selection.
