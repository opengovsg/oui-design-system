## Usage

```tsx
import { Link } from "@opengovsg/oui"
```

```tsx
<Link href="/page">Navigate to page</Link>
```

The `Link` component is built on top of [React Aria's Link](https://react-aria.adobe.com/Link). It supports navigation via the `href` prop, or custom press handling via the `onPress` prop.

> To ensure the Link component uses your framework's client-side router (instead of full page navigations), you need to set up the `RouterProvider` from `react-aria-components`. See the [Next.js](/docs/getting-started/next#set-up-react-aria-components-link-provider) or [Vite](/docs/getting-started/vite#set-up-react-aria-components-link-provider) setup guides, or refer to the [React Aria frameworks guide](https://react-aria.adobe.com/frameworks) for other frameworks.

### Adding icons

When adding multiple children (such as using an icon to the Link text) to the `Link` component, you might encounter some layout issues when using block level elements like `div` or `svg`. All children of the `Link` component automatically have the inline styles applied to them, but sizing and alignment of the start/endContent should still be handled by you manually.

## Events

Links with an href will be handled by the browser, or via a client side router. Links without an href will be rendered as a `<span role="link">` instead of an `<a>`. Use the `onPress` event to handle user interaction.
