This guide will help you set up OUI in a new or existing Vite project with React and Tailwind CSS v4. \
\
OUI has been tested with the following dependency versions:

- [Vite 4](https://vite.dev) or later
- [React 18](https://reactjs.org) or later
- [Tailwind CSS v4](https://tailwindcss.com/docs/installation)
- [Motion 12](https://motion.dev/docs/react) or later

## Create a new Vite project

If you're starting from scratch, create a new Vite project with React and TypeScript:

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
```

## Installation

<Steps>

<Step>
### Install dependencies

Install OUI packages and peer dependencies:

```package-install
npm install @opengovsg/oui @opengovsg/oui-theme react-aria-components motion
```

</Step>

<Step>
### Install Tailwind CSS v4

Install Tailwind CSS v4 and the Vite plugin:

```package-install
npm install tailwindcss @tailwindcss/vite
```

</Step>

<Step>
### Configure Vite

Add the Tailwind CSS plugin to your `vite.config.ts`:

```ts {1,8} title="vite.config.ts"
import tailwindcss from "@tailwindcss/vite"
import react from "@vitejs/plugin-react"
import { defineConfig } from "vite"

export default defineConfig({
  plugins: [
    // Add Tailwind CSS plugin
    tailwindcss(),
    react(),
  ],
})
```

</Step>

<Step>
### Set up your CSS file

Create or update your main CSS file (e.g., `src/globals.css`) to import the OUI theme:

```css title="src/globals.css"
@import "@opengovsg/oui-theme/tailwind.css";
/* 
 * Note: You may need to change the path relative to this css file to fit your
 * project structure, especially in a monorepo.
 */
@source "../path/to/node_modules/@opengovsg/oui-theme";
```

This import includes:

- Tailwind CSS v4 base styles
- OUI design tokens and theme variables
- React Aria Components integration via `tailwindcss-react-aria-components`
- Animation utilities via `tw-animate-css`

</Step>

<Step>
### Set up the Inter font
#### Using the Inter NPM package

You can use the [`inter-ui`](https://www.npmjs.com/package/inter-ui) NPM package to add the Inter font to your project.

Install the package:

```package-install
npm install inter-ui
```

Then, import the font CSS in your global CSS file:

```css {4-5,7-14} title="src/globals.css"
@import "@opengovsg/oui-theme/tailwind.css";
@source "../path/to/node_modules/@opengovsg/oui-theme";

@import "inter-ui/inter.css";
@import "inter-ui/inter-variable.css";

@layer base {
  :root {
    --font-sans: "Inter", ui-sans-serif, system-ui, sans-serif;

    @supports (font-variation-settings: normal) {
      --font-sans: "InterVariable", ui-sans-serif, system-ui, sans-serif;
    }
  }
}
```

#### Using Google Fonts

Alternatively, you can use [Google Fonts](https://fonts.google.com/selection?selection.family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900) to include the Inter font. Add the following `<link>` tag to the `<head>` of your `index.html`:

```html {4-9} title="public/index.html"
<head>
  <!-- ... -->
  <link rel="preconnect" href="https://fonts.googleapis.com" />
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
  <link
    href="https://fonts.googleapis.com/css2?family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&display=swap"
    rel="stylesheet"
  />
  <!-- ... -->
</head>
```

Then, ensure your Tailwind configuration uses the Inter font for the `--font-sans` CSS variable:

```css {4-6} title="src/globals.css"
@import "@opengovsg/oui-theme/tailwind.css";
@source "../path/to/node_modules/@opengovsg/oui-theme";

@theme {
  --font-sans: "Inter", ui-sans-serif, system-ui, sans-serif;
}
```

</Step>

<Step>
### Import CSS in your app

Make sure your CSS file is imported in your app entry point:

```tsx {3} title="src/main.tsx"
import React from "react"

import "./globals.css"

import ReactDOM from "react-dom/client"

import App from "./App"

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
```

</Step>

<Step>
### Set up `react-aria-components` Link provider
If your app uses routing (e.g., with TanStack Router, React Router, etc.), wrap your app with the `RouterProvider` from `react-aria-components`
to enable client-side navigation when using OUI's `Link` component:

```tsx title="app/providers.tsx (or wherever your providers are defined)"
import { RouterProvider } from "react-aria-components"
import { useHref, useNavigate } from "your-router"

export function Providers() {
  let navigate = useNavigate()

  return (
    <RouterProvider navigate={navigate} useHref={useHref}>
      <OtherProviders>{/* ... */}</OtherProviders>
    </RouterProvider>
  )
}
```

```tsx title="app/layout.tsx (or wherever your root layout is defined)"
import { Providers } from "./providers"

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en" className="antialiased">
      <body>
        <Providers>{children}</Providers>
      </body>
    </html>
  )
}
```

Read more about setting up client-side routing with `react-aria-components` in the [React Aria frameworks guide](https://react-aria.adobe.com/frameworks).

</Step>

<Step>
### Start using OUI components

You're all set! Start using OUI components in your app:

```tsx {1,6-8} title="src/some-component.tsx"
import { Button } from "@opengovsg/oui"

function SomeComponent() {
  return (
    <div className="flex min-h-screen items-center justify-center gap-4">
      <Button>Default</Button>
      <Button color="main">Main</Button>
      <Button variant="outline">Outline</Button>
    </div>
  )
}
```

</Step>

</Steps>

## TypeScript configuration

For the best TypeScript experience, ensure your `tsconfig.json` includes:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "moduleResolution": "bundler",
    "jsx": "react-jsx"
  }
}
```
