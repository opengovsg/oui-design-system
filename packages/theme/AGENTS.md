# @opengovsg/oui-theme — Agent guide

Tailwind theme tokens and config for the OUI design system. Paired with `@opengovsg/oui`.

Add to your Tailwind entrypoint:

```css
@import "@opengovsg/oui-theme/tailwind.css";
```

In a monorepo, also add a `@source` directive pointing to this package's installed location.

Full setup and customization: https://oui.open.gov.sg/llm/getting-started/theming.md
Component docs: https://oui.open.gov.sg/llms.txt
Forms (cross-cutting guide): https://oui.open.gov.sg/llm/guides/forms.md
